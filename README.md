# Machine Learning

A collection of machine learning, data analysis, data visualization, and predictive modeling projects implemented in Python Jupyter notebooks.

This repository is organized as a practical learning portfolio. It includes hands-on examples of data preprocessing, exploratory data analysis, regression, classification, and disease and fraud prediction.

## Highlights

- Data cleaning and preprocessing
- Exploratory data analysis and visualization
- Linear and logistic regression
- House price prediction
- Disease and heart attack prediction
- Cancer data analysis
- Online fraud detection
- FIFA World data exploration
- Market analysis

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/rizwanashafi/Machine-learning.git
cd Machine-learning
```

### 2. Create a virtual environment

```bash
python -m venv .venv
source .venv/bin/activate
```

On Windows:

```bash
.venv\Scripts\activate
```

### 3. Install Jupyter and common dependencies

```bash
python -m pip install --upgrade pip
python -m pip install jupyter numpy pandas matplotlib seaborn scikit-learn
```

Additional libraries may be required by individual notebooks. Check the notebook imports before running it.

### 4. Start Jupyter

```bash
jupyter notebook
```

Open any `.ipynb` file from the Jupyter interface and run the cells in order.
